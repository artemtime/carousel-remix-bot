# Установка — один раз, ~15 минут

Понадобятся: телефон с Telegram, компьютер с браузером (только для установки), банковская карта.

## Шаг 1. Бот в Telegram (2 минуты)

1. Откройте в Telegram **@BotFather** → `/newbot`.
2. Имя — любое, например «Мои карусели».
3. Адрес — латиницей и обязательно на `bot`, например `my_carousels_bot`.
4. BotFather пришлёт **токен** вида `1234567890:AA…`. Сохраните его — понадобится на шаге 4.

## Шаг 2. Ключ Google AI Studio (3 минуты)

1. Откройте https://aistudio.google.com/apikey и войдите своим Google-аккаунтом.
2. **Create API key** → **Create project** → имя `carousels` → **Create key**.
3. Скопируйте ключ (начинается на `AIza…`).
4. В той же строке, в колонке **Billing Tier**, нажмите **Set up billing** и привяжите карту. Без этого Google не рисует картинки.
5. Совет: в Google Cloud → «Оплата» → «Бюджеты» поставьте уведомление, например на $10 в месяц.

## Шаг 3. Ключ Apify (2 минуты)

1. Зарегистрируйтесь: https://console.apify.com/sign-up (бесплатно, карта не нужна).
2. Откройте https://console.apify.com/settings/integrations.
3. Скопируйте **Personal API token** (начинается на `apify_api_…`).

## Шаг 4. Запуск в Google Cloud (5–8 минут)

1. Откройте https://console.cloud.google.com и выберите вверху проект `carousels` (его создал шаг 2).
2. Нажмите значок терминала **«Активировать Cloud Shell»** справа вверху. Внизу откроется чёрное окно — это компьютер Google, на ваш ничего не ставится.
3. Вставьте туда эту команду целиком и нажмите Enter:

   ```bash
   git clone https://github.com/artemtime/carousel-remix-bot.git carousel-remix && cd carousel-remix && bash install.sh
   ```

   Если окно спросит «Username for 'https://github.com'» — в команде опечатка: скопируйте её отсюда ещё раз целиком.

4. Если вверху не выбран проект, скрипт покажет список ваших проектов — введите номер того, где делали ключ на шаге 2.
5. Скрипт по очереди спросит три ключа: Google, Apify, токен бота. Вставляйте их (символы при вставке не видны — так и должно быть) и нажимайте Enter. Скрипт сразу проверит все три и, если какой-то не подходит, скажет какой.
6. Если проект уже выбран вверху консоли, скрипт назовёт его и спросит «Верно?» — Enter, если это проект из шага 2.
7. Если Google попросит разрешение («Authorize Cloud Shell») — нажмите **Authorize**.
8. Шаг «6/8 Собираю и запускаю бота» идёт 3–5 минут молча — это нормально, ждите.
9. В конце появится: **«Готово! Откройте в Telegram @ваш_бот и нажмите /start»**. Вкладку Cloud Shell можно закрыть — бот работает в облаке.

## Шаг 5. Первый запуск

Откройте своего бота и нажмите **/start** — **сами, со своего Telegram**. Тот, кто нажал первым, становится хозяином бота: другим людям он отвечать не будет. Не пересылайте бота помощникам до своего /start.

## Обновление

Новая версия — та же команда в Cloud Shell, только `cd carousel-remix && git pull && bash install.sh`. На вопросы о ключах можно просто нажимать Enter: останутся прежние.

## Если что-то пошло не так

| Сообщение | Что делать |
|---|---|
| `PERMISSION_DENIED` / `billing` | Не привязана карта (шаг 2, п. 4) или выбран не тот проект вверху консоли. |
| Бот молчит | В Cloud Shell: `gcloud run services logs read carousel-bot --region europe-west1` — пришлите автору курса последние строки. |
| «Ключ Google AI Studio не подходит» | Скопируйте ключ заново (шаг 2), снова запустите `bash install.sh` и вставьте его. |
| «Ключ Apify не подходит» | Скопируйте токен заново (шаг 3), снова запустите `bash install.sh` и вставьте его. |
| «Токен бота не подходит» | @BotFather → /mybots → ваш бот → API Token, снова `bash install.sh`. |
| Спрашивает «Номер проекта» | Введите цифру проекта, в котором делали ключ на шаге 2 (обычно `carousels` или «Default Gemini Project»). |
| «Шаг не удался — выше ответ Google» | Скопируйте английский текст над этой строкой и пришлите в чат курса. |
